# Backend local

FastAPI com mocks em `app/services/demo_service.py`. A estrutura original de rotas, serviços, modelos, schemas e controladores foi preservada. O ponto de entrada `app/main.py` usa apenas o adaptador de demonstração e não abre o banco original nem o BigQuery.

Use `requirements-demo.txt` e consulte o README na raiz. `requirements_install.txt` é o manifesto original, mantido como referência.
